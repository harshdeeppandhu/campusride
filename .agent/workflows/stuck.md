---
description: Structured recovery when blocked or failing repeatedly
---
1. Stop changing code. Write down: goal, exact error, what was tried (attempts 1..n) in `docs/PROGRESS.md` > "Blockers".
2. Open `docs/11-TROUBLESHOOTING-PLAYBOOK.md`; run the matching diagnostic section.
3. Form 2 hypotheses; design the cheapest experiment to separate them; run it.
4. If still failing after the 3rd distinct attempt, STOP and ask the human with: summary, evidence, 2-3 options, your recommendation.
